# ontology

PLR の系のオントロジー（`Ontology.xlsx`）と、プロフィールのオントロジー（`Profile.xlsx`）です。xlsx が正本で、CSV はそれから作ったものです。書き方は [spreadsheet_format.md](spreadsheet_format.md)、直し方と配置のしかたはリポジトリの [README.md](../README.md) にあります。

## ダウンロードせずに見る

| | 表として（CSV） | Excel の見た目のまま（Microsoft のオンラインビューア。読むだけ） |
|---|---|---|
| Ontology | [Ontology.csv](Ontology.csv) | [Ontology.xlsx を開く](https://view.officeapps.live.com/op/view.aspx?src=https://raw.githubusercontent.com/assemblogue/plr-public/main/ontology/Ontology.xlsx) |
| Profile | [Profile.csv](Profile.csv) | [Profile.xlsx を開く](https://view.officeapps.live.com/op/view.aspx?src=https://raw.githubusercontent.com/assemblogue/plr-public/main/ontology/Profile.xlsx) |

CSV は GitHub が表として見せます（セルの色や結合は無い）。CSV は xlsx から作り、CI が一致を確かめているので、中身は xlsx と同じです。
